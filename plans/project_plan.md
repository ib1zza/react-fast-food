# План разработки веб-приложения Fast Food Cafe (Burger King Style)

Этот документ содержит пошаговый план по доработке и разворачиванию полноценного учебного веб-приложения фастфуд кафе на стеке React 19 + Vite + React Router 7 + Zustand + JSON Server.

---

## Этапы разработки

### 🛠 Этап 1: Инфраструктура и базовый макет (Выполнено)
- [x] Инициализация структуры проекта: `frontend/`, `backend/`, `plans/`.
- [x] Настройка `frontend` (React 19, Vite, React Router 7, Zustand, ESLint 9).
- [x] Настройка `backend` (`json-server` с базовой структурой `db.json`).
- [x] Оформление дизайна в стиле фастфуда (Brand Colors, Responsive Grid, Sticky Header, Drawer корзины).

---

### 🍔 Этап 2: Расширение функционала каталога и меню
1. **Модальное окно товара (Item Detail & Modifiers)**:
   - Отображение состава, калорийности, веса и белков/жиров/углеводов (БЖУ).
   - Выбор модификаторов (добавить сыр, бекон, халапеньо, убрать лук/соус).
   - Динамический перерасчет цены в зависимости от выбранных ингредиентов.

2. **Комбо-конструктор (Meal Builder)**:
   - Выбор основного бургера, размера картофеля (маленький/средний/большой) и напитка (соки, газировки, кофе).

3. **Поиск и фильтрация**:
   - Строка быстрого поиска по названиям и ингредиентам.
   - Фильтр "Новинки", "Хиты", "Острые блюда", "Вегетарианское".

---

### 🛒 Этап 3: Состояние корзины и Оформление заказа
1. **Продвинутый Store в Zustand**:
   - Сохранение корзины в `localStorage` (персистентность state).
   - Учет модификаторов в уникальном `cartItemId`.
   - Промокоды и расчет скидки (например, `KING2026` -> -15%).

2. **Страница / Модалка оформления заказа (Checkout Flow)**:
   - Выбор способа получения: Доставка или Самовывоз из ресторана.
   - Ввод адреса / выбор точки на карте или из списка ресторанов.
   - Выбор способа оплаты (Карта, СБП, Наличные).
   - Эмуляция оформления заказа с получением номера заказа и таймера готовности.

---

### 🎨 Этап 4: Анимации, UI/UX и микро-взаимодействия
- Анимация добавления товара в корзину (летающий иконка/эффект bounce).
- Skeleton Loaders при загрузке данных с backend (`json-server`).
- Тёмная тема / Адаптированный мобильный интерфейс (Mobile Bottom Bar для корзины и категорий).

---

### 🚀 Этап 5: Парсинг и наполнение реальными данными
- Запуск Node.js скрипта парсинга с `burgerkingrus.ru` (см. [data_scraping_guide.md](./data_scraping_guide.md)).
- Обновление `backend/db.json` настоящим ассортиментом, актуальными ценами и качественными изображениями.

## Как запустить проект локально

### Запуск Backend (JSON Server):
```bash
cd backend
npm install
npm run dev
```
Backend будет доступен по адресу `http://localhost:3001` (REST API: `http://localhost:3001/products`, `http://localhost:3001/categories`).

### Запуск Frontend (Vite + React 19):
```bash
cd frontend
npm install
npm run dev
```
Frontend будет доступен по адресу `http://localhost:3000`. Запросы к `/api/*` автоматически проксируются на `http://localhost:3001`.
