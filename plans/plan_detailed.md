# Детальный план итерации №1: Вывод товаров и категорий

**Подход:** Data-First (сначала проектирование типов, API и работы с данными, затем визуальный слой и стили).

---

## 1. Слой данных и API (Data & API Layer)

- [x] **Проверка контрактов:** Изучить структуру эндпоинтов `/categories` и `/products` в `backend/db.json`.
- [x] **Типизация:** Настроить/актуализировать TypeScript интерфейсы `Category` и `Product` в `frontend/src/types.ts`.
- [x] **API Клиент:** Создать модуль `frontend/src/api/catalogApi.ts` с методами:
  - `fetchCategories()` — получение списка категорий с `http://localhost:3001/categories`
  - `fetchProducts(categoryId?)` — получение списка товаров (всех или с фильтром по `categoryId`)

---

## 2. Управление состоянием (State Management & Custom Hooks)

- [x] **Кастомный хук:** Создать `frontend/src/hooks/useCatalog.ts` для связи UI с API.
- [x] **Переменные состояния:**
  - `categories` (массив категорий)
  - `products` (массив товаров)
  - `selectedCategoryId` (активная категория)
  - `isLoadingCategories`, `isLoadingProducts` (флаги загрузки)
  - `error` (обработка ошибок запросов)
- [x] **Функция выбора:** `selectCategory(id: string | null)` для переключения активной категории.

---

## 3. Лейаут и Сетка страницы (Layout & Page Skeleton)

- [ ] **Шапка (Header):** Создать `frontend/src/components/layout/Header.tsx` (логотип, название, иконка/кнопка корзины).
- [ ] **Каркас страницы:** Настроить в `frontend/src/pages/HomePage.tsx` 2-колоночную или адаптивную сетку (боковая панель навигации + основная область контента).

---

## 4. Компоненты на живых данных (Data-Driven UI Components)

- [ ] **Элемент категории (`CategoryItem`):** Компонент с иконкой/картинкой, названием и подсветкой при активном состоянии.
- [ ] **Навигация по категориям (`CategoryNav`):** Список/боковое меню категорий с передачей клика в `selectCategory`.
- [ ] **Карточка товара (`ProductCard`):** Изображение товара, название, описание, цена (`priceText`), кнопка «В корзину».
- [ ] **Сетка товаров (`ProductGrid`):** Рендеринг списка карточек товаров.

---

## 5. Фильтрация и обработка состояний

- [ ] **Error Handling:** Отображение плашки ошибки с возможностью повторить запрос при сбое связи с `json-server`.

---

## 6. UI Polish & Skeleton Loaders (Скелетоны и стилизация)

- [ ] **Skeleton Loaders:**
  - `CategorySkeleton` (серые пульсирующие блоки во время загрузки категорий)
  - `ProductSkeleton` (карточки-заглушки во время загрузки товаров)
- [ ] **Дизайн и стилизация:** Стилизовать элементы в `frontend/src/index.css` (современные тени, закругления, шрифты, микро-анимации).

---

## 7. Адаптивная верстка (Responsive & Mobile UI)

- [ ] **Адаптивность сетки:** Использование CSS Grid `repeat(auto-fill, minmax(240px, 1fr))` для гибкой подстройки количества колонок.
- [ ] **Мобильное меню категорий:** Превращение вертикального бокового меню в горизонтально скроллируемую плашку (sticky horizontal scroll) на экранах `< 768px`.
- [ ] **Тестирование разрешений:** Проверка отображения на Mobile (375px), Tablet (768px) и Desktop (1200px+).
