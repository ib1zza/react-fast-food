# Цель - сделать вывод товаров и категорий (Подход Data-First)

1. Настроить получение данных с локального сервера (типы + API клиент)
2. Написать логику управления состоянием и загрузки (Hooks / State)
3. Создать каркас страницы (Header + Сетка макета)
4. Сделать боковое меню с категориями на живых данных
5. Сделать карточки товаров и сетку на живых данных
6. Настроить связывание фильтрации категорий с товарами
7. Добавить таблицу стилей и скелетоны загрузки (Skeleton loaders)
8. Написать адаптив под разные разрешения (Mobile & Desktop)
